# Project Atmosphere

**Project Atmosphere** reimagines Minecraft's weather system, introducing dynamic cloud formations, intelligent seasonal forecasts, and a modular architecture ready for extreme weather events.  
Built for performance, compatibility, and future expansion, Project Atmosphere brings the sky to life.

---

## ✨ Features
- **Lightweight Dynamic Clouds** — Entities that drift naturally and react to weather conditions.
- **Weather-Synced Systems** — Cloud density adapts to rain, storms, and sunny skies in real time.
- **Temperature Management** — Supports Serene Seasons (if installed) or falls back to vanilla biome temperatures.
- **Modular Architecture** — Ready for expansion into storms, fogs, seasonal climates, and more.
- **Shader-Friendly** — Clouds use translucent entity rendering, fully compatible with shaders like Complementary, BSL, and SEUS.
- **Performance First** — Minimal entity ticking, optimized spawning, server-safe design.

---

## 🛠️ Compatibility
- **Forge 1.20.1**
- **GeckoLib 4.2.2**
- Optional: **Serene Seasons** for real-world seasonal temperatures

---

- Seasonal cloud patterns
