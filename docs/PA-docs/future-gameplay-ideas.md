# Project Atmosphere Future Gameplay Ideas

This file is a parking lot for gameplay ideas that are intentionally out of scope for the current implementation pass.

## Core Weather Ideas

- Wind as a real gameplay system that affects movement, projectiles, fog, particles, and cloud motion.
- Wetness and evaporation as a world-state loop that influences crops, terrain, and ambient humidity.
- Storm fronts that travel across the world and change pressure, cloud families, and local weather severity.

## Cloud System Ideas

- Cloud family branching beyond the current vapor -> cumulus -> storm path.
- Cloud merging that can create larger composite formations without visible seams.
- Cloud dissipation and re-seeding when environmental conditions decay.

## Survival / World Ideas

- Soil saturation and mud after prolonged rain.
- Freeze and thaw cycles tied to temperature and wind chill.
- Crop stress from drought, strong wind, and repeated storm exposure.

## Notes

- These ideas should stay separate from runtime code until a feature is explicitly selected.
- If a future pass needs a roadmap, this document can be turned into a proper feature backlog.
