# Geometry data model

Archetypes: CALVUS, CAPILLATUS, SUPERCELL, selected by exact native ID; unknown IDs rejected by this experimental compiler.

Definition: version, archetype, immutable CloudShapeProfile and seed. Geometry inputs finite/bounded, no visual profile dependency.

Program: immutable macro dimensions/axis/canopy recipe, unequal meso features, conservative bounds/signature. Complexity policy is independent of upload-slot limits. Sampling allocates nothing; scale selection distinguishes macro, meso and optional micro.

Current storm interpretation v4 compiles legacy authoring sectors into attached swept GrowthAxis records and branching Filament records. The legacy sector list is not GPU geometry. The packed program contains twelve RGBA header/hierarchy texels plus variable-length pairs per axis/ribbon; three complete structural-group bounds accelerate traversal without capping authoring. Details and offsets are in contracts/morphology.md.

The legacy dimension conversion and lobe-named feature policy are fixture migration adapters, not the final typed authoring schema. Production definitions need direct dimensions, explicit tower/canopy/ice controls and family applicability. Non-applicable calvus/capillatus wall values are explicitly migrated to zero; shapeId remains metadata. Materials are never a compiler input.

Instance: local-to-world frame, placement and separate material/lifecycle. Prototype fixtures only; production design requires server-owned versioned recipe through field sources/packet/copy paths.

Evidence: type, seed/profile/source hashes, framing/camera acknowledgment, shader/lighting arm, alpha readback, GPU timer validity, review verdict. CPU previews are preliminary diagnostics, not native acceptance.
