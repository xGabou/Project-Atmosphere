Goal
- Capture only the pixels of the cumulonimbus cloud linked to a given CloudRegion and apply them to the tornado as a texture. Assume you only have: (1) the CloudRegion instance and (2) the tornado world position. Everything else must be discovered at runtime from SimpleClouds and Minecraft.

High-Level Approach
- After SimpleClouds renders clouds for the current frame, sample its cloud framebuffers and composite them into your own TextureTarget while masking by the provided CloudRegion (center, radius, stretch, rotation). The mask is computed in world space per pixel using the clouds’ depth and the inverse camera matrices. The result is a single texture you can bind to the tornado material.

Data You Must Fetch (Runtime)
- Renderer: SimpleCloudsRenderer instance
  - Get via: SimpleCloudsRenderer.getOptionalInstance().orElse(null)
  - Abort if null.
- Framebuffers/textures (int GL texture ids)
  - Opaque color: renderer.getCloudTarget().getColorTextureId()
  - Opaque depth: renderer.getCloudTarget().getDepthTextureId()
  - Transparency (optional, for soft edges):
    - Accum: renderer.getCloudTransparencyTarget().getColorTextureId()
    - Revealage: renderer.getCloudTransparencyTarget().getRevealageTextureId()
- Matrices for world reconstruction
  - InverseWorldProjMat: new Matrix4f(RenderSystem.getProjectionMatrix()).invert()
  - InverseModelViewMat: new Matrix4f(currentPoseStack.last().pose()).invert()
- Output target
  - Create a TextureTarget (or equivalent) sized to the main framebuffer. This holds the masked clouds you will bind on the tornado.
- Region edge fade factor
  - Prefer: SimpleCloudsConstants.REGION_EDGE_FADE_FACTOR
  - If not accessible, use a reasonable default (e.g., 32.0) and expose as config.

When To Run (Ordering)
- Only run on the render thread.
- Only run when SimpleClouds is rendering this pass and for the primary eye:
  - if (!SimpleCloudsCompatHelper.renderThisPass() || !SimpleCloudsCompatHelper.isPrimaryPass()) return;
- Hook after clouds are rendered for the frame:
  - Default pipeline: after “after-sky” stage.
  - Shader packs (Iris etc.): after “after-level” stage.
  - If you cannot detect pipeline, hook both and guard with the checks above (no-op when nothing rendered).

Inputs You Already Have
- CloudRegion region: provides center (world X/Z), radius, stretch, rotation.
- Tornado world position (unused in masking, but available if you want to restrict sampling to a local screen region for perf).

Uniforms To Set For The Mask Shader
- Samplers
  - sampler2D CloudsTexture = opaque color texture id
  - sampler2D CloudDepthSampler = opaque depth texture id
  - sampler2D AccumTexture (optional)
  - sampler2D RevealageTexture (optional)
- Matrices (mat4)
  - InverseWorldProjMat
  - InverseModelViewMat
- Region (float/vec)
  - RegionCenter = vec2(region.getWorldX(), region.getWorldZ())
  - RegionRadius = region.getWorldRadius()
  - RegionStretch = region.getStretch(partialTick)
  - RegionRotation = region.getRotation(partialTick) // radians
  - EdgeFade = SimpleCloudsConstants.REGION_EDGE_FADE_FACTOR (or fallback)

Per-Pixel Logic (Fragment Shader)
- Reconstruct world position from cloud depth and inverse matrices, then compute an ellipse mask matching CloudRegion.

// Inputs: vec2 uv (0..1), ivec2 pixel = ivec2(gl_FragCoord.xy)
// Uniforms: samplers + matrices + RegionCenter/Radius/Stretch/Rotation/EdgeFade
// Output: vec4 masked cloud color
void main() {
  float depth = texture(CloudDepthSampler, uv).r;
  if (depth >= 1.0) { discard; } // no cloud at this pixel

  vec4 clip = vec4(uv * 2.0 - 1.0, depth * 2.0 - 1.0, 1.0);
  vec4 view = InverseWorldProjMat * clip; view /= view.w;
  vec4 world = InverseModelViewMat * view;
  vec2 wxz = world.xz;

  // CloudRegion ellipse in XZ with stretch+rotation
  vec2 p = wxz - RegionCenter;
  float cr = cos(-RegionRotation);
  float sr = sin(-RegionRotation);
  vec2 pr = vec2(p.x * cr - p.y * sr, p.x * sr + p.y * cr);
  pr.x *= RegionStretch;
  float d = length(pr);

  float inner = clamp((RegionRadius - d) * EdgeFade, 0.0, 1.0);
  float outer = 0.0;
  float fadeWidth = 1.0 / EdgeFade;
  if (d >= RegionRadius && d <= RegionRadius + fadeWidth) {
    outer = 1.0 - clamp((d - RegionRadius) * EdgeFade, 0.0, 1.0);
  }
  float mask = max(inner, outer);
  if (mask <= 0.0) { discard; }

  // Opaque clouds
  vec3 col = texture(CloudsTexture, uv).rgb;

  // Optional transparency (weighted blended OIT like SimpleClouds)
  // Only if you have AccumTexture/RevealageTexture bound
  // ivec2 ip = ivec2(gl_FragCoord.xy);
  // float reveal = texelFetch(RevealageTexture, ip, 0).r;
  // if (reveal < 1.0) {
  //   vec4 accum = texelFetch(AccumTexture, ip, 0);
  //   vec3 avg = accum.rgb / max(accum.a, 1e-5);
  //   col = avg * (1.0 - reveal) + col * reveal;
  // }

  fragColor = vec4(col * mask, 1.0);
}

Java-Side Steps (Per Frame)
1) Guard & obtain resources
   - if (!SimpleCloudsCompatHelper.renderThisPass() || !SimpleCloudsCompatHelper.isPrimaryPass()) return;
   - var opt = SimpleCloudsRenderer.getOptionalInstance(); if (opt.isEmpty()) return;
   - var r = opt.get();
   - int clouds = r.getCloudTarget().getColorTextureId();
   - int depth  = r.getCloudTarget().getDepthTextureId();
   - Optional: int accum = r.getCloudTransparencyTarget().getColorTextureId();
   - Optional: int reveal = r.getCloudTransparencyTarget().getRevealageTextureId();
2) Build matrices for this frame
   - Matrix4f proj = RenderSystem.getProjectionMatrix();
   - Matrix4f modelView = currentPoseStack.last().pose();
   - invProj = new Matrix4f(proj).invert(); invModelView = new Matrix4f(modelView).invert();
3) Prepare output target
   - TextureTarget out = ensureAllocated(width=main.width, height=main.height);
   - out.clear(Minecraft.ON_OSX); out.bindWrite(true);
4) Bind shader & uniforms
   - setSampler("CloudsTexture", clouds);
   - setSampler("CloudDepthSampler", depth);
   - Optional: setSampler("AccumTexture", accum); setSampler("RevealageTexture", reveal);
   - set("InverseWorldProjMat", invProj); set("InverseModelViewMat", invModelView);
   - set("RegionCenter", new Vector2f(region.getWorldX(), region.getWorldZ()));
   - set("RegionRadius", region.getWorldRadius());
   - set("RegionStretch", region.getStretch(partialTick));
   - set("RegionRotation", region.getRotation(partialTick));
   - set("EdgeFade", SimpleCloudsConstants.REGION_EDGE_FADE_FACTOR or fallback);
5) Draw fullscreen triangle/quad
   - RenderSystem.disableDepthTest();
   - Issue full-screen draw. The shader writes only masked pixels.
6) Use the result on the tornado
   - int tornadoTex = out.getColorTextureId();
   - Bind as a sampler in your tornado material/shader.

Choosing The Hook
- Default pipeline: hook after SimpleCloudsRenderer.renderAfterSky(...) is called (e.g., Forge RenderLevelStageEvent AFTER_SKY or later BEFORE_WEATHER).
- Shader packs (Iris): hook after SimpleCloudsRenderer.renderAfterLevel(...).
- If unsure, run in both stages; the guard checks will prevent duplicate work when SimpleClouds hasn’t rendered.

Reliability Notes
- CloudTarget holds all cloud types; the region mask is what isolates the linked cumulonimbus.
- Use the same partialTick for region stretch/rotation as used for cloud rendering that frame.
- If transparency targets are unavailable/null, skip OIT and just use opaque CloudsTexture.
- Always run on the render thread (RenderSystem.assertOnRenderThread or recordRenderCall).

Failure Handling
- If SimpleCloudsRenderer is absent or resources are null, log debug and skip for this frame.
- If dimensions mismatch the main target, reallocate the output TextureTarget.

Optional Optimization
- Restrict the full-screen pass to a tight scissor/quad around the projected ellipse of the CloudRegion to reduce fill cost near the tornado.

Outcome
- You produce a single texture (the output TextureTarget color) that contains only the pixels of the linked cumulonimbus region for this frame, suitable to bind directly on the tornado.
